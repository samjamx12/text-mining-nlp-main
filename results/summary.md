# Results Summary

This project contains four notebook workflows:

1. **NLP Toolkit Comparison**  
   Compares NLTK and spaCy outputs for tokenization, POS tagging, named entity recognition, chunking, and dependency parsing.

2. **Sentiment Analysis Pipeline**  
   Evaluates VADER under different preprocessing conditions and compares it with Naive Bayes text classification.

3. **Named Entity Recognition Classification**  
   Builds SVM-based NER classifiers with dictionary features and word embeddings, then analyzes class-level performance.

4. **Topic Classification with Transformers**  
   Compares RoBERTa fine-tuning against a classical Naive Bayes baseline on selected 20 Newsgroups categories.

The notebooks preserve their original outputs where available. Re-running all experiments may require external datasets and, for transformer experiments, a GPU-enabled environment.
